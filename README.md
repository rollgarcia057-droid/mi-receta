# mi receta: Arepas con queso

## Ingredientes
- 2 tazas de harina de maíz precocida
- 2 tazas de agua tibia
- 1 cucharadita de sal
- Queso rallado

## Preparación
1. Mezcla el agua con la sal.
2. Agrega la harina poco a poco y amasa.
3. Forma las arepas y rellénalas con queso.
4. Cocínalas en sartén 5 minutos por lado.
